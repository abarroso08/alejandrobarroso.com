A home server is a useful reminder that the internet can still feel personal. This project is a modest collection of services for files, notes, and experiments.

## What I’m learning

The interesting part is not any single container. It is learning how reliability emerges from boring habits: clear backups, sensible defaults, and making the easiest path the safe one.
